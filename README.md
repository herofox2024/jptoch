﻿﻿﻿﻿﻿﻿﻿# EPUB 日译中翻译工具

一个基于大模型 API 的日文 EPUB 自动翻译工具，提供桌面 GUI，支持将日文 EPUB 翻译为简体中文，并尽量保留原书结构（目录、链接、章节）。

## 新增能力（v2.0）

- **UI 全面重构**：从单页表单改为"左侧导航 + 右侧多页面"布局
  - 左侧深色导航栏，4 个页面切换：任务 / 接口配置 / 翻译选项 / 状态监控
  - 卡片化组件（LabelFrame 包裹各功能模块）
  - 主题配色系统（`THEME` 字典统一管理颜色）
  - 标题显示版本号"EPUB 翻译器 V2.0.1"
- **接口配置改为下拉框**：服务提供方从 Radiobutton 改为 Combobox 下拉选择
- **状态监控页增强**：
  - 8 个统计卡片：已完成、总文本块、新增术语、耗时、速度、API 请求、成功率、失败数
  - 翻译进度条
  - 实时翻译展示：逐条显示当前翻译的日文原文与中文译文
- **翻译状态输出优化**：进度条下方的详细状态信息改为输出到日志文件，UI 仅保留卡片和实时翻译展示
- **自动页面切换**：点击"开始翻译"后自动跳转到状态监控页
- **translator.py 回调增强**：`translate_batch` 新增 `item_callback` 参数，每条翻译完成时回调原文与译文
- **打包支持**：支持 PyInstaller 打包为单文件 `EPUB日译中V2.0.exe`

## 功能概览

- EPUB 正文翻译（段落、标题、列表、引用等常见标签）
- 目录（NCX）标题翻译
- 超链接结构保留（保留 `href`，替换文本）
- Ruby 注音处理（提取正文语义，去除注音标签干扰）
- 图片占位文本过滤（避免误翻）
- 翻页方向设置（中文习惯 / 保持原版）
- 缓存机制（减少重复翻译）
- 术语表支持（`glossary.json`）
- 多线程批量翻译
- 性能预设模式（默认/适中/极端）

## 新增能力（v1.5_a）

- **连接池优化**：连接池大小与并发数匹配，消除 "Connection pool is full" 警告
- **UI 改进**：翻译完成时状态显示 "翻译完成" 而非 "翻译中..."

## 使用方法

### 启动 GUI

```bash
python app.py
```

或直接运行打包后的 `EPUB日译中V2.0.exe`

### 基本步骤

1. 选择输入 EPUB（支持拖拽文件到输入框）
2. 确认输出路径
3. 点击左侧导航栏切换到「接口配置」页面
4. 从下拉框选择服务提供方（DeepSeek / Doubao / Sakura / Gemini / 自定义）
5. 设置 API Key（Sakura 可留空，会使用 `sk-local`）
6. 检查 `Base URL` 与 `Model`（切换服务提供方会自动填充默认值）
7. 点击左侧导航栏切换到「翻译选项」页面
8. 选择性能预设（默认 / 适中 / 极端）
9. 选择翻页方向（中文习惯 / 保持原版）
10. 可选：导入术语表 JSON、开启术语提取或启用术语表
11. 点击左侧导航栏回到「任务」页面
12. 点击「▶ 开始翻译」按钮
13. 界面自动跳转到「状态监控」页面，实时查看：
    - 统计卡片：已完成、总文本块、新增术语、耗时、速度、API请求、成功率、失败数
    - 进度条
    - 实时翻译：逐条显示日文原文与中文译文

## 性能预设说明

| 预设 | 并发数 | 批量大小 | 批量总字符 | 单文本上限 | 分块大小 | 预估提速 |
|------|--------|----------|-----------|-----------|---------|---------|
| 默认 | 5 | 4 | 800 | 200 | 1200 | 基准 |
| 适中 | 12 | 10 | 4000 | 600 | 2500 | +40~60% |
| 极端 | 25 | 15 | 8000 | 1000 | 4000 | +100%+ |

- **默认**：稳定安全，适合免费账户或首次使用
- **适中**：推荐配置，效率与稳定性兼顾
- **极端**：高风险模式，仅建议付费账户、高配电脑、稳定网络使用
  - 可能频繁触发 API 限流（429 错误）
  - 大批量失败回退代价高
  - 内存占用增加

## API Key 与后端说明

- `DeepSeek`：
  - 默认 URL：`https://api.deepseek.com/chat/completions`
  - 默认模型：`deepseek-v4-flash`
  - 需要 API Key
- `Doubao`（火山引擎豆包）：
  - 默认 URL：`https://ark.cn-beijing.volces.com/api/v3/chat/completions`
  - 默认模型：`Doubao-Seed-1.6-flash`
  - 需要 API Key
- `Sakura`（本地/自建 OpenAI 兼容服务）：
  - 默认 URL：`http://127.0.0.1:8080/v1/chat/completions`
  - 默认模型：`sakura-v1.0`
  - API Key 可留空（程序会使用 `sk-local`）
- `Gemini`（OpenAI 兼容入口）：
  - 默认 URL：`https://generativelanguage.googleapis.com/v1beta/openai/chat/completions`
  - 默认模型：`gemini-2.5-flash`
  - 需要 API Key
- `Custom`：
  - 需自行填写可用的 `Base URL`、`Model`、API Key

```bash
# Linux/macOS
export DEEPSEEK_API_KEY=your-api-key
export DOUBAO_API_KEY=your-api-key
```

## 缓存与日志

- 缓存：`~/.epub_translator/cache.json`
- 日志：`~/.epub_translator/logs/app-YYYYMMDD.log`

## 项目结构

- `app.py`：GUI 主程序
- `translator.py`：翻译核心逻辑（API 调用、批处理、缓存、术语处理）
- `epub_io.py`：EPUB 读写、目录与翻页设置
- `requirements.txt`：依赖清单

## 注意事项

- 大文件翻译耗时较长，请耐心等待
- 建议翻译后在阅读器中检查排版与章节跳转
- 若使用自建/代理网关，请确认接口兼容 `chat/completions`
